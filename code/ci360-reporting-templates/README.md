# CI 360 Reporting Templates

This repository contains some templates to get value more quickly out of the CI 360 Unified Data Model (UDM). The sql files in the templates folder also serve as inspiration and guidance on how to combine the tables. The templates are a starting point, for you to enrich based on reporting requirements.

The SKILL.md file provides instructions that help your AI tool adapt existing templates or create new ones.

## Requirements
- The UDM should be deployed in a relational database.
- The code is tested on UDM schema version 22.
- The code is tested on a Postgres database. Minor changes may be needed to support other database platforms.
