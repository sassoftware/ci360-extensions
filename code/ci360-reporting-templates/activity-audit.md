# Activity Audit

[← Back to all reporting templates](README.md)


For a given subject-id, show all activities that occurred over a given time period.  This report is helpful to audit all activities of a test identity and verify that the data is correctly represented.
- Forms submitted
- Pages visted
- Sessions
- Visits
- Events

These UDM tables are used as input:
- SESSION_DETAILS
- IDENTITY_MAP
- IDENTITY_ATTRIBUTES
- FORM_DETAILS
- PAGE_DETAILS
- VISIT_DETAILS
- CUSTOM_EVENTS
